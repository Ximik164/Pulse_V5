# Pulse Messenger (дипломный проект)

Веб-мессенджер с регистрацией, чатами в реальном времени и сохранением данных в JSON-файле.

## Возможности

- Регистрация и авторизация (JWT + bcrypt)
- Общий, личные и групповые чаты
- Сообщения в реальном времени (WebSocket)
- Список контактов и создание личного чата
- Профиль пользователя
- Настройки интерфейса
- Локальная база данных JSON (данные сохраняются после перезапуска, без нативных модулей)
- Аватары пользователей (клик по фото в профиле)
- Отправка изображений в чат (скрепка)
- Истории на 24 часа
- Статусы сообщений: отправлено ✓ / доставлено ✓✓ / прочитано (синие ✓✓)
- Создание групп с приглашением участников
- Поиск пользователей в контактах
- Админ-панель (статистика, удаление пользователей)

**Админ:** `admin` / `admin123`

## Быстрый старт

```bash
cd "путь/к/pulse-messenger"
npm install
npm start
```

Откройте в браузере: **http://localhost:3000**

## Структура

```
├── server.js      # API + WebSocket
├── db.js          # Хранилище data/store.json
├── assets/        # Логотип Pulse
├── auth.js        # Авторизация (клиент)
├── chat.js        # Чаты и сообщения (клиент)
├── app.js         # Навигация, контакты, настройки
├── index.html
├── styles.css
└── data/          # Файл store.json (создаётся автоматически)
```

## Для защиты диплома

**Стек:** Node.js, Express, WebSocket, JSON-файл БД, HTML/CSS/JS.

**Архитектура:** клиент-сервер, REST API для CRUD, WebSocket для push-сообщений.

**Безопасность:** хеширование паролей, JWT на HTTP и WebSocket.

## Переменные окружения

Скопируйте `.env.example` в `.env` или задайте переменные в Render:

```env
PORT=3000
JWT_SECRET=ваш-секретный-ключ
NODE_ENV=production
```
